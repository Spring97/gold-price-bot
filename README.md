# 黄金价格推送机器人

自动抓取各类黄金价格行情数据，在各机构开市时段每半小时推送到企业微信群。

## 功能

机器人每半小时（:00 和 :30）自动抓取并推送以下 5 类黄金价格：

| 序号 | 品种 | 数据来源 | 单位 |
|------|------|----------|------|
| 1 | 金店-周大福 | 金投网 API | 元/克 |
| 2 | 银行-美元账户黄金 | 金投网 API（工行纸黄金美元） | 美元/盎司 |
| 3 | 银行-人民币账户黄金 | 金投网 API（工行纸黄金人民币） | 元/克 |
| 4 | 伦敦金 | 金投网 API（现货黄金 XAU） | 美元/盎司 |
| 5 | 上海-AU99.99 | 金投网 API（上海黄金交易所） | 元/克 |

## 推送时段

| 时段 | 时间（北京时间） | 说明 |
|------|------|------|
| 日市 | 09:00 - 15:30 | 上海黄金交易所日市 + 银行 + 伦敦金 |
| 夜市 | 20:00 - 02:30 | 上海黄金交易所夜市 + 银行 + 伦敦金 |

- **频率**：每半小时发送一次（:00 和 :30）
- **工作日**：周一至周五（夜市延续到周六凌晨 02:30）

## 使用方法

### 一键启动（推荐）

```bash
bash /workspace/gold_price_bot/start.sh
```

### 手动操作

```bash
# 立即强制推送一次（忽略开市时段判断）
python3.11 /workspace/gold_price_bot/main.py --once --force

# 在开市时段推送（自动判断是否在 :00/:30 时间点）
python3.11 /workspace/gold_price_bot/main.py --once

# 测试数据获取（不发送消息）
python3.11 /workspace/gold_price_bot/main.py --test

# 查看当前调度信息
python3.11 /workspace/gold_price_bot/main.py --schedule

# 启动守护进程模式
python3.11 /workspace/gold_price_bot/main.py --daemon
```

### cron 配置

cron 任务已配置为每小时的 :00 和 :30 执行：

```
0,30 * * * * /workspace/gold_price_bot/cron_send.sh
```

脚本内置开市时段判断，非开市时段自动跳过。

## 数据来源

所有数据来自金投网（cngold.org）的行情 API 接口：

```
https://api.jijinhao.com/quoteCenter/realTime.htm
```
